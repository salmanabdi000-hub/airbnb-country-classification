RUNNING THE NOTEBOOK IN GOOGLE COLAB

1. Open https://colab.research.google.com/ and upload airbnb_classification.ipynb.
2. Run the imports and setup cell first.
3. Use the left Files panel to upload your authorised copy of airbnb.csv.
   The file must appear at /content/airbnb.csv.
4. Run all remaining cells in order. Cross-validation and tuning may take several minutes.
5. Download the results when prompted, and save the executed notebook separately.

The notebook imports google.colab and uses /content paths: it targets Colab.
requirements.txt records the original run's package versions; current Colab
versions may differ. Fresh execution of this publication copy is not yet verified.

course provider. Exact original source and licence remain unresolved; this
